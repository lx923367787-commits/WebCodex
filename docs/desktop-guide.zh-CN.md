# WebCodex Desktop 使用指南

**外部工具与账号：** 模型 CLI 由用户在每台 Runner 电脑自行安装、登录或配置自己的 key，再配置并验证 Runner。WebCodex 交付对接代码和通用运行依赖，不交付另一用户配置好的工具环境。见[工具、账号与迁移规则](EXTERNAL_TOOLS.md#简体中文)。

[English](desktop-guide.md) | [简体中文](desktop-guide.zh-CN.md)

Desktop 负责准备本机项目和管理连接；你在 ChatGPT 等 AI 客户端中发起工作。首次安装、Tunnel 配置和系统权限请看[安装与连接指南](desktop-install.zh-CN.md)。

## 第一次使用

1. 在欢迎页选择 **在此电脑使用 WebCodex**。这是普通个人使用的推荐入口。
2. 点击 **配置 WebCodex** 启动服务和 Runner。无需先选择项目或文件夹。
3. Tunnel 配置检测位于 **可选：检查 ChatGPT 安全隧道配置** 中。在此填写 Tunnel ID 和 API key 后点击“保存配置”，即可优先使用本机配置文件，无需重启。没有 Tunnel 配置也可以先启动本机服务；配置齐全时，可勾选配置后连接 ChatGPT。
4. 首页分别显示服务、连接和项目状态。需要执行项目任务时，在 **项目** 中创建命名项目、添加源文件夹和配置团队；每个聊天单独绑定项目。
5. 点击侧栏的 **连接**。选择 **OpenAI Secure Tunnel** 后，再点击 **启动安全隧道**。仅选择连接方式不会启动进程。
6. 隧道就绪后，按照连接页指引在 ChatGPT 中填入 Tunnel ID，再执行一次真实项目读取。

**本地隧道就绪不等于 ChatGPT 已连接或任意项目任务可执行。** 零项目也可以连接；任务开始前仍需验证项目绑定及其目录权限。

如果已有远程 Server，欢迎页选择 **连接现有 Server**，填写地址和配对码，无需选择文件夹即可连接。Desktop 连接页会显示远程 Server 信息，外部连接由 Server 管理者负责。

项目团队策略、普通子 Agent 和 CLI 托管任务使用当前用户的 PAT。新配对签发及 `tokens create-local` 的默认用户权限包含 `communication:read`、`communication:manage`、`plugin:inspect` 和 `plugin:invoke`；这不会改变已有 PAT 的权限。旧连接若收到权限不足，请由用户明确重新登录或配对刷新凭据。桌面端不会自动扩大旧令牌权限，也不会改用管理员凭据执行团队任务。

如果只想临时使用一个项目，选择 **快速共享项目**，再选择连接提供方。Quick Share 是独立的临时使用方式；首页提供连接交接信息和停止入口。

## 每天从首页开始

首页分别显示服务状态、连接状态和项目是否可用。服务停止时点击 **启动**；服务和 Runner 就绪且 Tunnel 配置齐全时即可 **启动安全隧道**，无需创建项目。

项目及文件夹统一由 **项目** 管理。首页只提供项目状态和管理入口，不提供全局项目切换。创建或移除命名项目不会停止全局服务和连接。具体聊天的项目绑定及任务目录授权独立校验；已有项目注册、团队设置和聊天绑定在升级后保留。

**查看运行诊断** 包含运行方式和停止控制。项目尚未配置可以稍后创建；不要通过扩大允许目录来解决任务权限错误。

## 连接与故障恢复

连接页先展示当前状态和可执行操作，下方提供 ChatGPT 连接步骤。配置缺失时，Tunnel 配置检测自动展开；这里可以保存配置，并显示当前来源和是否完整。API key 使用密码输入框，已保存的值不会回显。

| 看到的情况 | 下一步 |
| --- | --- |
| 本机运行环境未就绪 | 回首页恢复运行环境；需要时重新配置同一个项目 |
| Tunnel ID 或 API key 未检测到 | 在配置区填写并保存 Tunnel ID 和 API key；仅使用环境变量时才需退出重开 |
| 启动失败且没有活动隧道 | 保留当前选择，修复配置或网络后再次点击启动 |
| 已有隧道报错 | 点击停止，成功后重新启动；停止失败会保留错误和重试入口 |
| 隧道就绪但剪贴板交接失败 | 在连接页重试“复制 Tunnel ID”，或选中 ID 手动复制，无需重启 |
| 隧道就绪，等待 ChatGPT | 在 ChatGPT 配置 Tunnel，并列出所选项目的顶层文件（空目录也可作为结果） |

**设置 → OpenAI Tunnel 网络** 管理自动、直连和自定义 HTTP 代理。更改运行中隧道的代理前先停止隧道，保存后再启动。

## 活动、设置和后台运行

**活动** 按最新在前显示操作记录。可搜索内容或来源，也可选择 **只看警告和错误**；筛选不会删除记录。

**设置** 包含语言、登录时启动、Tunnel 网络和诊断信息。语言也可以在左下角直接切换。支持简体中文、English、日本語、한국어、Deutsch、Français；选择会保存，重开后恢复，活动时间按所选语言格式显示。系统托盘菜单和原始后端诊断仍使用英文，系统文件选择器的语言由操作系统决定。

关闭窗口只是隐藏到菜单栏或系统托盘，已启动的运行环境仍在后台工作。托盘中的 **退出 WebCodex** 才会结束 Desktop 及其管理的进程。首页的 **停止 Desktop 管理的运行环境** 会停止运行环境并更新保存的启动偏好；这些操作不会终止其他自行启动的 WebCodex 进程。

macOS 使用 **⌘ + 1–5**，Windows 使用 **Ctrl + 1–5** 切换五个页面。这些导航快捷键在输入框和语言选择框内同样生效，普通输入及复制、粘贴等文本编辑快捷键不受影响。可用 Tab 聚焦按钮，用 Enter 激活；诊断折叠项也支持键盘操作。

首页的运行控制和设置页的技术诊断默认折叠。主动停止后显示“已停止”，点击“启动”继续。活动页优先显示操作结果，勾选“显示进程详情”查看常规进程事件。Tunnel ID 和密钥在连接页配置；API key 不回显。
